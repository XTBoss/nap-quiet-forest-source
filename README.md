# 安静小森林

给教室午睡或自修用的安静小游戏。页面会听室内音量：一段时间内分贝持续低于设定值，就种一棵小树；要是分贝持续高于太吵阈值，就会少一棵小树。小树凑够数量，会自动合成大树。

点「结束」会留下这场汇总。用「启动」打开时，记录会写入旁边的 `data/日期.json`，也可在设置里导入、导出。不保存分贝曲线或录音。当前屏幕上的树只留在这个标签页里（刷新还在，关掉标签页就清空）。

## 班级笑脸墙

顶部切换到「班级笑脸墙」，在学生管理中粘贴姓名名单（每行一位，也支持逗号分隔）。内置 60 张离线卡通头像，按名单顺序自动分配，也可修改姓名、选择头像、上传照片或调整顺序；移出的学生保留积分和记录，可以恢复。首次使用不预置学生数据。

- 头像下直接加 1 分或扣 1 分，也可以勾选多位学生后批量操作。
- 加分、扣分独立累计，每 5 分分别生成 1 个笑脸、苦脸，余数继续累计。
- 点击笑脸兑换贴纸，默认 1 个笑脸兑换 1 张，可在班级设置里修改比例。也可手动消除笑脸、苦脸并选填备注。
- 兑换和消除不清掉零头或历史分数。「撤销上一步」还原最近一次积分、兑换、消除或整批操作，并保留撤销记录。
- 点击姓名查看个人记录。展示模式隐藏操作按钮；全屏和自适应紧凑布局方便全班同屏，手机和人数较多时可滚动。
- 每次更改自动保存到 `data/classroom.json`，同时缓存到当前浏览器。页面显示保存状态；本地服务断开时会明确提示仅浏览器保存。文件使用版本校验，避免多个窗口静默覆盖数据。
- 班级设置支持导出、导入 JSON 备份。导入会确认后替换当前班级，请先导出旧数据；备份含头像及完整操作记录。班级容量为 120 位学生（含已移出学生）。

小森林监听中切换到笑脸墙，会结束并记录当前监听。两个模块各自保存数据，清空森林记录不会清空学生积分。Windows 和 Mac 启动器均提供班级文件保存接口。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://127.0.0.1:43147`）。

用「开始监听教室」时，浏览器会申请麦克风权限。请把平板或电脑放在能听到整间教室的位置。页面里的分贝是按这台设备麦克风估算的，不是实验室声级计，建议安静下来后点一次「用现在的音量当作安静标准」。

没有麦克风、或只是想看效果，可以用「先演示一下」。演示默认是安静教室，右下角可以切换「教室开始吵 / 教室安静下来」。

## 可调项目

- 安静阈值（分贝）
- 种一棵小树需要安静多久（例如 20 分钟、40 分钟）
- 太吵阈值（分贝）
- 持续太吵多久会少一棵小树
- 几棵小树合成一棵大树

短暂的一声响大约 2 秒内不会立刻清掉种树进度，减少门响、翻身把整段安静作废。少树则要持续超过太吵阈值一整段设定时间才会发生。

## 发给别人

```bash
npm run pack
```

生成 `安静小森林.zip`。对方解压后双击「启动」（Mac 用 `.command`，Windows 用 `.bat`）。麦克风功能需要 localhost，所以必须走启动，不要直接打开 `index.html`。
