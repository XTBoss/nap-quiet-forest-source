# 安静小森林 · 班级笑脸墙

一款在教室电脑或大屏上运行的本地班级管理工具，包含两个可以随时切换的模块：

- **安静小森林**：监听教室音量，用种树和合成大树鼓励午睡、自修时保持安静。
- **班级笑脸墙**：把全班学生放在同一屏幕上，老师可以直接加分、扣分，并用累计笑脸兑换贴纸。

应用在本机运行，不需要账号或云服务。麦克风声音只用于即时估算音量，不会录音，也不会保存音频。

## 班级笑脸墙

在顶部切换到「班级笑脸墙」，第一次使用时进入「学生管理」，粘贴全班姓名即可建立名单。姓名支持每行一位，也支持使用逗号、分号或制表符分隔。

### 积分规则

| 操作 | 结果 |
| --- | --- |
| 加分 | 每次增加 1 分；累计满 5 分生成 1 个笑脸 |
| 扣分 | 每次增加 1 个扣分记录；累计满 5 分生成 1 个苦脸 |
| 兑换贴纸 | 默认 1 个笑脸兑换 1 张贴纸，比例可在班级设置中修改 |
| 消除表情 | 老师可以手动消除笑脸或苦脸，并选填原因 |
| 撤销 | 还原最近一次加分、扣分、兑换、消除或整批操作 |

加分和扣分分别累计，不会互相抵消。兑换或消除表情不会清除未满 5 分的余数，也不会删除历史记录。

例如，一名学生累计加 13 分、扣 7 分，会显示 `2 个笑脸 + 加分进度 3/5`，以及 `1 个苦脸 + 扣分进度 2/5`。

### 日常操作

- 每个学生的头像下方都有加分、扣分按钮。
- 勾选多名学生后，可以整批加分或扣分；撤销时也会整批还原。
- 内置 60 张离线卡通头像，按名单顺序自动分配，也可以重新选择或上传照片。
- 点击学生姓名查看个人积分、兑换和撤销记录。
- 学生可以调整顺序或暂时移出班级；移出后数据仍会保留，并可随时恢复。
- 「展示模式」会隐藏操作按钮，适合向全班展示；也支持全屏。
- 页面会根据学生人数自动切换布局，48 人可在常见的 `1366 × 768` 教室屏幕中完整显示，手机端则使用双列滚动布局。
- 班级最多保存 120 位学生，包括已经移出的学生。

## 安静小森林

开始监听后，页面会根据设定的音量阈值和持续时间更新森林：

- 教室持续安静一段时间，种下一棵小树。
- 教室持续太吵一段时间，减少一棵小树。
- 小树达到设定数量后，自动合成一棵大树。
- 短暂噪声有约 2 秒缓冲，不会因为门响或翻身立即清空种树进度。

可以调整安静阈值、太吵阈值、种树时间、少树时间，以及合成大树需要的小树数量。没有麦克风或只想查看效果时，可以使用「先演示一下」。

监听中切换到笑脸墙，会自动结束本场监听并保存汇总。

## 直接使用

可以从 GitHub 的 [Releases](https://github.com/XTBoss/nap-quiet-forest-source/releases) 页面下载自动打包好的 `安静小森林.zip`。每次推送到 `main` 会更新「最新打包」；打 `v*` 标签（例如 `v1.0.0`）会发布对应版本。也可以在仓库的 Actions 页面下载同一次构建的压缩包。

1. 下载并解压 `安静小森林.zip`，不要直接在压缩包中打开文件。
2. Mac 双击 `启动.command`；如果系统阻止运行，请右键选择「打开」。
3. Windows 双击 `启动.bat`；如果出现安全提示，选择「仍要运行」。
4. 保持启动窗口开启，在自动打开的浏览器页面中使用应用。

不要直接双击 `index.html`。麦克风和本地文件保存依赖启动器提供的 `localhost` 服务。

## 数据保存与备份

| 数据 | 保存位置 | 说明 |
| --- | --- | --- |
| 班级名单、积分、头像和操作记录 | `data/classroom.json` | 每次操作自动保存，同时在当前浏览器保留缓存 |
| 小森林场次汇总 | `data/日期.json` | 点击「结束」或切换到笑脸墙时保存 |
| 当前屏幕上的树 | 当前浏览器标签页 | 刷新后仍在，关闭标签页后清空 |
| 森林设置 | 当前浏览器 | 保存阈值、时长和合成数量 |

班级名称下方会显示保存状态。关闭应用前，应确认显示「已保存到本地文件」。如果启动服务断开，页面会提示当前更改仅保存在浏览器中。

班级设置支持导出和导入 JSON 备份。备份包含学生头像及完整操作记录；导入会替换当前班级，因此建议先导出现有数据。文件保存带有版本检查，可防止多个浏览器窗口无提示地互相覆盖。

清空小森林或森林历史不会删除班级数据，两个模块的数据互相独立。

## 本地开发

需要 Node.js `20.19+` 或 `22.12+`。

```bash
npm install
npm run dev
```

开发服务默认运行在 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

运行自动化测试：

```bash
npm test
```

生成生产构建：

```bash
npm run build
```

## 重新打包

```bash
npm run pack
```

命令会生成 `安静小森林.zip`，其中包含网页资源、Mac 和 Windows 启动器，以及空的 `data` 文件夹。收件人解压后即可双击启动，无需安装 Node.js。
