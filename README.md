# 午睡小森林

给幼儿园午睡用的教室安静小游戏。页面会听室内音量：一段时间内分贝持续低于设定值，就种一棵小树；要是分贝持续高于太吵阈值，就会少一棵小树。小树凑够数量，会自动合成大树。

不保存历史曲线或过往记录，只保留当前这次打开页面时的小森林（刷新同一标签页还在，关掉标签页就清空）。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://127.0.0.1:43147`）。

老师用「开始监听教室」时，浏览器会申请麦克风权限。请把平板或电脑放在能听到整间教室的位置。页面里的分贝是按这台设备麦克风估算的，不是实验室声级计，建议午睡安静下来后点一次「用现在的音量当作安静标准」。

没有麦克风、或只是想看效果，可以用「先演示一下」。演示默认是安静教室，右下角可以切换「教室开始吵 / 教室安静下来」。

## 可调项目

- 安静阈值（分贝）
- 种一棵小树需要安静多久（例如 20 分钟、40 分钟）
- 太吵阈值（分贝）
- 持续太吵多久会少一棵小树
- 几棵小树合成一棵大树

短暂的一声响大约 2 秒内不会立刻清掉种树进度，减少门响、翻身把整段安静作废。少树则要持续超过太吵阈值一整段设定时间才会发生。

## 打包静态文件

```bash
npm run build
```

生成的 `dist/` 可以放到任意静态网站，用现代浏览器打开即可。麦克风功能需要 localhost 或 HTTPS。
